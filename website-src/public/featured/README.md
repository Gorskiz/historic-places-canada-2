# Featured photographs

These are unmodified copies of photographs already held in this project's image archive, sourced from the Canadian Register of Historic Places. Original image URLs, record links, captions and credits are retained in `src/data/featured-places.json` and the credits are displayed beside each photograph. The repository's data-use terms apply.

The small selection is bundled so the homepage does not wait for a database query or an external image host. To change the selection, update the manifest and corresponding image files together. Record the actual pixel dimensions; the gallery uses them for its portrait, landscape, panorama and small-image layouts. Images are displayed with `object-fit: scale-down` so they are never cropped or enlarged beyond their intrinsic dimensions.

If the first photograph changes, also update its preload in `index.html`. Keep both language records and the original credits. Names and captions may remain in English where that is how the original French record was supplied.
